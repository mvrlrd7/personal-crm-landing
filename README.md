# Лендинг «Личная CRM»

Одностраничный статичный сайт: Astro + Tailwind CSS 4. Все кнопки ведут в приложение.

## Команды

- `pnpm install` — установить зависимости
- `pnpm dev` — открыть сайт для разработки: http://localhost:4321
- `pnpm build` — собрать готовый сайт в папку `dist/`
- `pnpm preview` — посмотреть собранный сайт

## Где что лежит

- `src/pages/index.astro` — страница и все тексты
- `src/components/` — повторяющиеся блоки: кнопка, карточка, метка секции, цветной квадрат, решётка
- `src/styles/tokens.css` — цвета, шрифт, размеры текста и отступы (менять только здесь)
- `src/config.ts` — адрес приложения `APP_URL`
- `public/fonts/` — шрифт Golos Text
- `design/` — макет
