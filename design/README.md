# Handoff: Лендинг «Личная CRM»

## Overview
Одностраничный статичный лендинг продукта «Личная CRM» (адресная книга с заметками о знакомых). Единственное целевое действие — переход в приложение (кнопки «Создать первую карточку» и ссылка «Войти»).

**Стек реализации:** Astro + Tailwind CSS 4, статичная страница (без клиентского JS, кроме необязательного — см. «Interactions»).

## About the Design Files
Файлы в этой папке — **дизайн-референсы, сделанные в HTML** (прототипы, показывающие внешний вид и поведение), а не продакшн-код. Задача — **воссоздать их в Astro + Tailwind 4** идиоматично: компоненты `.astro`, утилиты Tailwind, токены через `@theme`. Не копируйте HTML/inline-стили напрямую.

- `Landing Mobile.dc.html` — мобильная версия (ширина колонки 390px).
- `Landing Desktop.dc.html` — десктоп (контейнер max-width 1280px).
- `landing-text.md` — исходный текст лендинга (meta title/description тоже там).
- `support.js` — рантайм прототипов, нужен только чтобы открыть `.dc.html` в браузере. В проект не переносить.

Открыть референс: положить файлы рядом и открыть `.dc.html` в браузере. Разметка между `<x-dc>…</x-dc>` — обычный HTML с inline-стилями; `<sc-if>` — условный рендер вариантов (см. «Варианты финального блока»).

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, рамки — финальные. Воспроизводить пиксель-в-пиксель.

## Адаптивность — одна страница, две раскладки
Делать одну страницу, mobile-first:
- `< 1024px` — мобильная раскладка (`Landing Mobile`), контент центрирован, max-width 390px… на планшетах допустимо растянуть до ~560px с теми же пропорциями.
- `≥ 1024px` (`lg:`) — десктопная раскладка (`Landing Desktop`), max-width 1280px, по центру.
Фон страницы за контейнером: `#e9e8e4`; сам контейнер белый `#fff`.
Двухколоночные ряды десктопа сделаны на `flex-wrap` с `flex: 7 1 480px` / `flex: 5 1 360px` — при сужении естественно падают в одну колонку.

Tailwind 4:
```css
@import "tailwindcss";
@theme {
  --font-sans: "Golos Text", sans-serif;
  --color-ink: #000; --color-paper: #fff; --color-page: #e9e8e4;
  --color-red: #d8281c; --color-yellow: #f5c518; --color-blue: #1d4ea0;
}
```

Радиусов нет (везде 0). Теней нет.

### 02 Проблема
H2 «Знакомых всё больше, а помнить о них всё труднее». Три пункта-строки с линиями 1px сверху (последняя ещё и снизу), сетка 48 / 56px + текст; маркер — квадрат 14 / 16px: **blue, yellow, red** по порядку. Деск.: заголовок слева (5/12), список справа (7/12, сдвинут вниз на 52px).

### 03 Как это работает
H2 «Три шага. Без настройки и обучения». Решётка:
- Моб.: 2 колонки `64px 1fr`, 3 строки — номерная ячейка (28px/700) + белая ячейка (заголовок 18/600 + текст 15).
- Деск.: 3 колонки; каждая — ячейка-номер высотой 96px (44px/700, номер прижат вниз-влево) над белой ячейкой.
Цвета номеров: 1 — yellow (чёрный текст), 2 — red (белый), 3 — blue (белый).

### Варианты финального блока (в прототипе — Tweaks)
В прототипах есть переключатели, их **не реализовывать**, взять дефолт:
- `finalShape` = **«Полоса»** (альтернативы «Решётка», «Три квадрата» — только для обсуждения).
- `finalVisual` (десктоп) = **«Три карточки»** (альтернативы «Поиск», «История общения» есть в разметке под `<sc-if>`).

## Interactions & Behavior
- Все CTA и «Войти» ведут в приложение: вынести URL в одну константу (`APP_URL`, напр. `https://app.example.com`, уточнить у заказчика); «Войти» может вести на `APP_URL/login`.
- Hover ссылок: `opacity:.85`; CTA — инверсия (см. выше). Переходы не заданы — можно `transition-colors 150ms`.
- Анимаций нет. Состояний загрузки/ошибок/форм нет.
- Клиентский JS не нужен.
